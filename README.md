📊 Análisis de Ventas - Power BI
Este proyecto consiste en el análisis de una base de datos de facturación de clientes durante un año, con el objetivo de identificar patrones de ventas, rentabilidad y comportamiento por canal, producto y ubicación geográfica.
**Herramientas**
Power BI
Power Query
Excel
**KPIs desarrollados**
Ventas Totales
Margen
% Rentabilidad
Top Clientes
**Transformaciones - Power Query**
Limpieza de datos
Creación de columnas de margen
Normalización de dimensiones
**Visualizaciones**
Ventas por mes
Ventas por canal
Ventas por ciudad
